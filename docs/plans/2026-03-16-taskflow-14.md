# Recurring Tasks Added via Update Never Spawn Next Instance — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers-extended-cc:subagent-driven-development (if subagents available) or superpowers-extended-cc:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When `update()` adds a `recurrenceRule` to a task that has no `recurrenceGroupId`, generate and persist a new `recurrenceGroupId` so that `complete()` correctly spawns the next recurrence instance.

**Architecture:** The fix is a one-line addition inside the existing `recurrenceRule` update block in `TaskService.update()`. The `complete()` method already guards on both fields (`!existing.recurrenceRule || !existing.recurrenceGroupId`); the only missing piece is that `update()` never writes `recurrenceGroupId` for converted tasks. A regression test proves the contract end-to-end.

**Tech Stack:** TypeScript, Hono, Drizzle ORM, SQLite (better-sqlite3), Vitest

---

## Root Cause

`taskService.ts:220-222` — the `update()` method stores `recurrenceRule` but never touches `recurrenceGroupId`:

```ts
if (input.recurrenceRule !== undefined) {
  updates.recurrenceRule = input.recurrenceRule ? JSON.stringify(input.recurrenceRule) : null;
  // BUG: recurrenceGroupId is never set here
}
```

`taskService.ts:314-316` — `complete()` requires both fields to proceed:

```ts
if (!existing.recurrenceRule || !existing.recurrenceGroupId) {
  return;  // exits silently — next instance never spawned
}
```

  ```ts
  it('should assign recurrenceGroupId when adding a recurrence rule via update, enabling complete() to spawn next instance', async () => {
    // Start as a one-time task

    expect(task.recurrenceGroupId).toBeNull();

    // Convert to recurring via update
    const updated = await service.update(task.id, {

    // complete() must spawn the next instance
    const result = await service.complete(updated.id);
    expect(result.nextInstance).not.toBeNull();
    expect(result.nextInstance!.recurrenceGroupId).toBe(updated.recurrenceGroupId);
  });
  ```

  Find this block in `update()` (around line 220):

  ```ts
  if (input.recurrenceRule !== undefined) {
    updates.recurrenceRule = input.recurrenceRule ? JSON.stringify(input.recurrenceRule) : null;
  }
  ```

  Replace with:

  ```ts
  if (input.recurrenceRule !== undefined) {
    updates.recurrenceRule = input.recurrenceRule ? JSON.stringify(input.recurrenceRule) : null;
    if (input.recurrenceRule && !existing.recurrenceGroupId) {
      updates.recurrenceGroupId = nanoid();
    }
  }
  ```

  Note: `nanoid` is already imported at the top of the file. `existing` is already in scope (line 205). No new imports needed.
