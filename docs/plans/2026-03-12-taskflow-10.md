# AI Scheduler Smoke Test — Validation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:executing-plans to implement this plan task-by-task.

**Goal:** Validate that the ai-scheduler pipeline executed all stages correctly for this smoke test issue, then close and clean up.

**Architecture:** This is a meta-validation plan — no code changes are needed. The steps confirm that label transitions, plan file creation, and GitHub comments all happened as expected. Final step closes and deletes the issue.

**Tech Stack:** GitHub CLI (`gh`), ai-scheduler (Python daemon at `~/projects/ai-scheduler/`)

**Native Tasks:** #1 (label transitions), #2 (verify artifacts), #3 (close/clean)

---

### Task 1: Verify pipeline artifacts exist

**Files:**
- Check: `docs/plans/2026-03-12-taskflow-10.md` (this file)
- Check: GitHub issue #10 comments

**Step 1: Confirm plan file exists**

```bash
ls -la ~/projects/taskflow/docs/plans/
```

Expected: `2026-03-12-taskflow-10.md` is present.

**Step 2: Confirm comment was posted on the issue**

```bash
gh issue view 10 --repo saabendtsen/taskflow --json comments --jq '.comments[].body'
```

Expected: At least one comment containing the plan file path `docs/plans/2026-03-12-taskflow-10.md`.

**Step 3: Confirm labels are correct**

```bash
gh issue view 10 --repo saabendtsen/taskflow --json labels --jq '[.labels[].name]'
```

Expected: `["ai-plan-ready"]` — `ai-ready` removed, `ai-plan-ready` added.

### Task 2: Validate label transition integrity

**Step 1: Check no stale ai-* labels remain**

```bash
gh issue view 10 --repo saabendtsen/taskflow --json labels --jq '[.labels[].name] | map(select(startswith("ai-")))'
```

Expected output:
```json
["ai-plan-ready"]
```

If any unexpected labels are present (e.g. `ai-failed`, `ai-ready`), remove them:

```bash

gh issue edit 10 --repo saabendtsen/taskflow --remove-label "ai-failed"
```

### Task 3: Close and clean up smoke test issue

**Step 1: Post validation summary comment**

```bash
gh issue comment 10 --repo saabendtsen/taskflow --body "$(cat <<'EOF'
AI scheduler pipeline validation complete.

**Validated stages:**
- [x] Issue picked up (ai-ready → ai-planning)
- [x] Plan created at docs/plans/2026-03-12-taskflow-10.md
- [x] Plan path commented on issue
- [x] Label set to ai-plan-ready

Closing this smoke test issue. Safe to delete.
EOF
)"
```

**Step 2: Close the issue**

```bash
gh issue close 10 --repo saabendtsen/taskflow --comment "Smoke test complete — closing."
```

Expected: Issue state changes to `CLOSED`.

**Step 3: Delete the issue (manual)**

GitHub CLI does not support deleting issues. Delete via web UI:
- Navigate to https://github.com/saabendtsen/taskflow/issues/10
- Use the "Delete issue" option in the issue menu (requires repo admin)

Or via GraphQL:
```bash
gh api graphql -f query='
  mutation {
    deleteIssue(input: {issueId: "I_kwDORRjBnc6c..."}) {
      repository { name }
    }
  }
'
```

Note: Get the issue node ID first with:
```bash
gh issue view 10 --repo saabendtsen/taskflow --json id --jq '.id'
```
