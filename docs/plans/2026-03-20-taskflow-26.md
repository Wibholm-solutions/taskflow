# Plan: Fix reorder test — upcoming task leaks into active bucket

**Issue:** [#26](https://github.com/Wibholm-solutions/taskflow/issues/26)
**Date:** 2026-03-20

## Context

The reorder validation test (`api.test.ts:287`) creates an "Upcoming" task with `notBefore: '2026-03-17'`. That date is now in the past, so the task appears in the active bucket instead of upcoming, breaking the assertion on line 341.

The `taskService.test.ts` file already handles this correctly by using `vi.useFakeTimers()` + `vi.setSystemTime('2026-03-16T10:00:00.000Z')` before any test that depends on `notBefore: '2026-03-17'`. The `api.test.ts` reorder test simply lacks this.

## Approach

Use `vi.useFakeTimers()` to freeze time before 2026-03-17, consistent with the existing pattern in `taskService.test.ts`.
