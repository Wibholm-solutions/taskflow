# Issue #12: PUT /tasks Validation Gap — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers-extended-cc:subagent-driven-development (if subagents available) or superpowers-extended-cc:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reject invalid task data on `PUT /tasks/:id` (specifically empty/whitespace titles) and add comprehensive API tests covering all invalid-update scenarios.

**Architecture:** The route already calls `validateUpdateInput` for priority, deadline, notBefore, recurrenceRule, and subtasks — the only gap is that empty/whitespace-only titles are accepted. Fix `validateUpdateInput` in `server/src/routes/tasks.ts` to mirror the create-side emptiness check, then add targeted API tests for every invalid-update case described in the issue.

**Tech Stack:** Hono (Node.js), Vitest, TypeScript

## Context: What already works

Before touching code, note what the issue description says vs. current state:

- `validateUpdateInput` **already exists** at `server/src/routes/tasks.ts:101-119`
- `PUT /tasks/:id` **already calls** it at line 198
- Priority, deadline, notBefore, recurrenceRule, and subtask mutations are **already validated**
- The sole remaining functional gap: `title: ""` and `title: "   "` pass validation (create uses `!body.title` which catches both; update only checks `typeof body.title !== 'string'`)

The plan therefore has two tasks: fix the title check, then fill the test coverage gap.

```typescript
// Current (lines 103-104):
if (body.title !== undefined && typeof body.title !== 'string') return 'title must be a string';
if (body.title !== undefined && body.title.length > 200) return 'title must be 200 chars or less';
```

Replace with:

```typescript
if (body.title !== undefined && typeof body.title !== 'string') return 'title must be a string';
if (body.title !== undefined && body.title.trim().length === 0) return 'title must not be empty';
if (body.title !== undefined && body.title.length > 200) return 'title must be 200 chars or less';
```
