# Plan: Add dashboard.healthcheck.url label (Issue #40)

## Context

The server-dashboard can perform HTTP healthchecks on Docker containers with a `dashboard.healthcheck.url` label. Taskflow needs this label to enable centralized monitoring.

## Current State

- Health endpoint **already exists**: `GET /todo/api/health` returns `{ "status": "ok", "version": "..." }` (200 OK)
- `docker-compose.yml` has no `labels` section yet
- Internal port is 3000, external is 3101

## Plan

### Task 1: Add healthcheck label to docker-compose.yml

**File:** `docker-compose.yml`

Add a `labels` section to the `app` service:

```yaml
labels:
  - "dashboard.healthcheck.url=http://localhost:3000/todo/api/health"
```

Note: Uses internal port 3000 (localhost inside the container), matching the existing healthcheck endpoint.

## Verification

1. `docker compose config` — validate YAML syntax
2. Rebuild/restart container and confirm label: `docker inspect taskflow --format '{{index .Config.Labels "dashboard.healthcheck.url"}}'`
3. Curl the health endpoint: `curl http://localhost:3101/todo/api/health`
